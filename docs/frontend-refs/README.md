# frontend-refs

This folder is the frozen design source of truth for Fortivo's frontend. The palette,
fonts, severity ramp, Tailwind config snippet, colour-collision rules and background
assets kept here are the complete set of visual decisions for the app — nothing else
is approved. If a colour, font, icon or background does not appear in this folder, it
should not appear in the app. When the design and the code disagree, the code is wrong.
